# open-data

Personal data I keep public so that tools and AI agents can read it directly from this repository.

Everything here is plain Markdown, easy to read for humans and easy to parse for agents.

## Contents

| File | Description |
| --- | --- |
| [stocks.md](stocks.md) | Companies I track: stocks I hold and stocks on my watchlist. |

## Notes for agents

- Read the raw files, e.g. `https://raw.githubusercontent.com/otsobide/open-data/main/stocks.md`.
- Each file is organized into sections with a table per section. Column meanings are stated in the file.
- Nothing here is financial advice; it is just a record of what I'm interested in.
